# Changelog

All notable changes are recorded here.

## [Unreleased]

### Added

- Added the application-library foundation: save-before-apply preferences, atomic settings files, installed/portable directory probes, native UI rendering and the approved separate font resources. The explicit notices generator now produces a complete offline catalogue; runnable desktop composition follows separately.

- Offline corpus inspection reports schema-v2 conditions, expected values, frozen reference metadata, sample readiness and unavailable inputs. Anchor annotation writes a separate unverified proposal, and a contributor capture guide explains reproducible ladders and privacy protections (R-QA-1, R-QA-3, R-DOC-1).

### Fixed

- The native UI library paints theme surfaces and text together, including dark/light/dark transitions. The offline licence catalogue excludes Apache boilerplate from copyright-holder metadata and preserves the actual AccessKit source attribution.

### Changed

- Migrated the Pyro Gateway transcription to schema version two with unknown conditions left null; human verification is still required (R-QA-1).
