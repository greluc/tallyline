## Verification boundary

Drawn tests inspect actual reference-browser, manual-review and confirmation role faces, sizes and explicit line heights, including current price/SCU values, alongside installed font bytes, widget rectangles, semantic colours, keyboard button focus and the requested modal scrim. Public manual-review tests include exact values beyond binary floating-point precision and explicit confirmation commands. They do not establish native Windows rendering, 100/125/150% display scaling, a native 200% text-size setting, rendered-pixel contrast or Linux acceptance. Drawn legal-browser contracts also cover exact elected/upstream expressions, notice and GPL copying, missing-list recovery, close/reopen selection, semantic selection tokens and body typography, and a 1,000-component catalogue at 800×640 and 100/200% zoom in all three themes. These checks do not establish native pixel rendering or installed-system acceptance. Fan Kit pinning tests remain unchanged.

## Desktop shell composition

The shell uses the supplied geometry: a 40 px minimum top bar, 28 px minimum status bar, 232 px sidebar, 48 px rail and 16 px content padding. Bars wrap instead of clipping. The sidebar is used when its width and two content gutters leave at least 640 logical pixels for the page; narrower viewports use directly focusable named rail actions. The accepted minimum remains 800 × 640 logical pixels. The archive's 1440 px breakpoint and F6/Ctrl+B shortcuts are proposals and are not adopted.

The top bar carries the plain Tallyline title, actual submission mode and mapped UEX environment. The native title bar supplies window controls. No logo, Fan Kit artwork, capture controls or speculative AI state is added to the shell. Home, Reference data, Manual Report, Submission queue and history, Settings, Help/About and return to unfinished setup retain their existing commands and guards. Selected navigation has a separate visible treatment; every icon action retains its accessible name and tooltip. Navigation uses ordinary Tab and Space operation without an overlay or stored appearance preference.

The bottom summary retains queue counts and held-job navigation, current reference/cache/offline state, reference age at the last update, loading and save state. Global account review/keep choices, release feedback, update link/dismiss, storage failures and reference diagnostics/staff notices remain above every page in a bounded scrollable notice area. Reference details expands the per-endpoint timestamps. Staff text remains literal and the reference model caps it at 280 Unicode characters. Page content scrolls independently, and passive results do not select a page or request focus.

Headless tests exercise the actual drawn shell rather than a geometry-only model. They inspect panel/control bounds, the selected accent surface and Material Symbols family, setup guards, Tab/Space/Escape behaviour, retained content focus after passive failures, real reference age and clock mismatch, and concurrent account/update/error actions. The 800 × 640 matrix includes Home, Reference, Settings and populated Manual pages at ordinary and double zoom in every theme; Settings save still emits its existing command. Manual input groups wrap at narrow widths, and clipped Manual/stock-settings inputs reveal themselves only when they gain explicit focus. Passive updates do not repeatedly scroll a focused field. Native visual acceptance, operating-system scaling and Linux acceptance remain separate gates.
